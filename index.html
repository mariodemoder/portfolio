Tedear S.A. | El mundo empresarial (2007)

Obtuve experiencia en muchos rubros de negocio donde se maneja gran volumen de datos y transacciones y en diversas tecnologías para brindar un sólido circuito operacional.

Con una base sólida y oficial de MS SQL Server se implementaba en modalidad partner Calipso Wan a diferentes Pymes. Una plataforma ERP que entre otras cosas permitía: optimizar procesos empresariales, acceder a datos integrales y unificados, y reducir tiempos y costos de procesos.

Como la empresa brindaba la instalación estándar de la plataforma y luego amoldaba los módulos a las particularidades del cliente, el código fuente de Calipso es una caja negra en donde, para saber lo que hacía internamente, se necesitaba sí o sí una ingeniería inversa de procesos y leer con atención los pasos del SQL Profiler.

Se ganaba mucha eficiencia y velocidad de procesamiento al pulir la programación desde la base de datos: Stored Procedures, Jobs, Views y Triggers con buenas prácticas y optimizados.

Se inyectaba código para controlar el comportamiento del DOM del HTML: VBScript y JavaScript (tanto para validación de datos como para alertas, información o confirmaciones).

Módulos desarrollados: Ventas - Compras - Stock - Recursos Humanos - Contabilidad - Legales - Usuarios - Módulos Personalizados.

Funcionalidades de cada módulo: Integraciones - Validación y Reglas del Negocio - Exportación de Datos - Reportes - Cubos OLAP.

Infraestructura: MS SQL Server - Calipso WAN - Office.

Herramientas: SQL Profiler - Office - NotePad++ - Crystal Reports 9.

Lenguajes: SQL - Visual Basic - VBScript - JavaScript - XML - notaciones JSON.
